# Apache License 2.0 text for crates that omit it

Canonical, unmodified Apache License 2.0 text (identical to Snake's own
`LICENSE`). These published crates declare Apache-2.0 (or MIT OR Apache-2.0)
in their package metadata but do not include a license file, so the release
license collector attaches this copy:

- `russh` 0.64.1, `russh-cryptovec` 0.62.0, `russh-util` 0.52.0
  (https://github.com/Eugeny/russh, Apache-2.0)
- `delegate` 0.13.5 (https://github.com/kobzol/rust-delegate, MIT OR Apache-2.0;
  a build-time procedural macro, not embedded in the executable)

Source for each crate is linked in the generated Cargo inventory. Snake does
not modify these crates.
