# Terminal Color Schemes and Import

A standalone "Pure White" theme is now available: once selected in "Settings → Terminal → Color Theme", the terminal always uses a `#FFFFFF` white background, `#1F2328` dark body text, a blue cursor and a light blue selection, even when the app switches to the dark appearance. ANSI, log and field highlighting all use dark variants suited to a white background; the new theme does not change the default selection.

Settings → Terminal offers Ghostty Clear, Pure White, Classic, Vivid, Tokyo Night, Catppuccin Latte/Mocha, Gruvbox Light/Dark and Solarized Light/Dark. New installations default to Ghostty Clear; the first upgrade migrates the previous Tokyo Night selection into Ghostty Clear while other built-in or already imported themes keep their selection. The migration runs only once, so manually choosing Tokyo Night afterwards is preserved. Except for the fixed white surface of Pure White, other built-in themes follow the app's light/dark appearance, and light variants share the white background adapted by Snake. Only the palette of the existing SwiftTerm views is replaced; SSH is not disconnected and the terminal buffer is not cleared.

Ghostty Clear follows the [Ghostty default configuration](https://github.com/ghostty-org/ghostty/blob/a2e440396403385680008e456a741a7776091412/src/config/Config.zig) and the [ANSI palette](https://github.com/ghostty-org/ghostty/blob/a2e440396403385680008e456a741a7776091412/src/terminal/color.zig): the dark variant uses a `#282C34` charcoal background with `#FFFFFF` body text, avoiding the greyish blue-violet body color; ANSI dim grey, red and the bright colors are lifted, and every named color except the ANSI black used as the base surface reaches at least 4.5:1 against the background. Body text reaches at least 10:1 against the background, and at least 7:1 against the selection and the text inside the cursor. The settings preview gains a grey comment sample. This design is Snake's own readability adaptation rather than a verbatim Ghostty theme or renderer; it does not change remote 256-color, True Color or faint text attributes.

`.itermcolors` files can be imported: they are read by the system property-list parser and must provide foreground, background and ANSI colors 0–15; missing cursor and selection colors fall back to explicit defaults. Files are capped at 1 MB. A single-variant scheme keeps its original colors in both app appearances; a file containing Light and Dark variants follows the appearance. Parsed schemes are stored in `~/Library/Application Support/Snake/TerminalThemes/` and can be deleted in Settings. If the selected imported theme is missing or deleted, Snake falls back to Ghostty Clear and notifies the user.

The colored file list in the preview is only a sample. Snake no longer injects `ls/ll` aliases, `LS_COLORS`, `CLICOLOR` or color hints into the remote shell; ANSI/True Color emitted by the server itself is still displayed normally. The OSC 7 working-directory shell hook is unchanged, and local log and field highlighting still only affects drawing, never the SSH data or copied content.

ANSI/SGR and OSC color sequences define terminal display behavior rather than a single theme-file protocol. Base16/Base24 are cross-application palette conventions; this version imports only `.itermcolors` and reads no other theme format. The pinned upstream versions, MIT license and white-background adjustments of the built-in palettes are documented in `Vendor/TerminalThemes/`; the Tokyo Night origin is in `Vendor/TokyoNight/`.
