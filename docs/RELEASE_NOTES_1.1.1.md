# Snake 1.1.1

## 本次更新（相对 1.1.0）

- 新增中英双语界面。简体中文为源语言、默认语言与回退语言；设置「外观 › 语言」可在
  跟随系统 / 简体中文 / English 之间切换，切换即时生效并会被记住。
- 界面文案全部改为可本地化资源，系统权限弹窗与 Info.plist 权限说明提供中英两版。
- SSH 连接失败阶段（TCP 解析／连接、SSH 会话初始化／握手、PTY、认证等）改由结构化
  stage 码驱动，报错信息随界面语言显示，不再混入中文硬编码。
- 设置页布局重构：四个页面统一滚动与分组样式、内容顶部对齐，说明文字改为区块脚注；
  窗口由固定尺寸改为可调整大小（默认 640×560，最小 560×460）。
- 修复英文界面下设置页的横向裁切：快捷键录键框不再被标签列压缩，终端字号等标签不再被窗口边缘切断。
- 终端配色预览在较大字号下换行显示，不再裁切。
- 设置「终端」标签图标由 `textformat` 改为 `terminal`，修复中文系统下显示为「格式」字形的问题。
- 新增 `README.en.md` 与 `docs/en/` 英文文档，中英文档互加语言切换链接。

## 下载与安装

- 文件：`Snake-1.1.1-macos-arm64.dmg`，同时提供 `.dmg.sha256`。
- 系统：macOS 15+，Apple Silicon（M 系列）；本次不包含 Intel 版本。
- 打开 DMG，将 Snake 拖到 Applications，复制结束后推出 DMG。
- 更新前退出旧版；已有用户配置不随安装包分发，也不会因复制应用被清空。
  语言选择保存在本机偏好设置中，升级后保留。

## 发布限制

当前构建为本地 ad-hoc 签名，未完成 Developer ID 签名与 Apple 公证，首次打开可能被系统拦截。
详见 [安装说明](INSTALL.md)。页面及真实安装后的连接行为由用户验收。
磁盘映射仍需单独安装 macFUSE / sshfs；本安装包不自动安装系统依赖。
本次未修复既有挂载 `invalidMapping` 测试问题，不将其列为已通过项目。
