# Snake 1.1.2

## 本次更新（相对 1.1.1）

- 「打开远程文件」的缓存改为可配置：设置「传输 › 打开远程文件」可更换保存目录（默认系统
  缓存目录），设置自动清理的保留时长（默认 7 天）与容量上限（默认 500 MB），并可查看当前
  占用、随时手动清理。缓存写入改为「临时文件 + 原子替换」，中断或失败不会留下残缺文件；
  缓存文件权限 `0600`、Snake 自建目录 `0700`，默认位置不参与系统备份。
- 修复删除 SSH 会话可能连带删除用户文件的问题：此前会递归删除缓存目录下该会话的整个
  子目录，用户放在里面的文件会一并消失；现在只清理名字符合 Snake 缓存命名规则的副本，
  目录里还有其它内容时则保留目录。删除会话的确认弹窗也补充了该说明。
- 新增「每主机连接数」（2–16，默认 8）：同时进行多个传输时，对同一台主机的分片与逐文件
  传输连接总数受该值约束，超出的传输排队等待并在记录里显示「等待中」，避免多标签同时传输
  把同一服务器打成连接风暴。每个标签的常驻连接、每个上传批次的操作连接不计入该值。
- 修复多个 SFTP 标签时从访达拖拽上传可能落到另一个标签的问题：文件此前会进到那个标签
  当时浏览的远程目录、进度与记录也记在那边；现在只有屏幕上正在显示的那个标签接收拖拽。
- 修复上传排队期间记录显示为「传输中」而非「等待中」的问题，与下载侧保持一致。

## 下载与安装

- 文件：`Snake-1.1.2-macos-arm64.dmg`，同时提供 `.dmg.sha256`。
- 系统：macOS 15+，Apple Silicon（M 系列）；本次不包含 Intel 版本。
- 打开 DMG，将 Snake 拖到 Applications，复制结束后推出 DMG。
- 更新前退出旧版；已有用户配置不随安装包分发，也不会因复制应用被清空。

## 发布限制

当前构建为本地 ad-hoc 签名，未完成 Developer ID 签名与 Apple 公证，首次打开可能被系统拦截。
详见 [安装说明](INSTALL.md)。页面及真实安装后的连接行为由用户验收。
磁盘映射仍需单独安装 macFUSE / sshfs；本安装包不自动安装系统依赖。
既有挂载 `invalidMapping` 测试问题仍未修复，不将其列为已通过项目。
