# Finder 拖拽上传：重新实现与验收

更新：2026-09-09。适用于当前 Swift/AppKit + Rust 实现。原生手势验收尚未通过，不能作为已修复发布说明。

## 使用规则

- 从访达拖入本地文件、多个文件或文件夹，松手前展示目标目录提示。
- 终端：上传到最近一次 OSC 7 报告的 shell 目录；目录未知时弹出绝对路径确认框，尝试通过独立 SFTP 连接预填主目录。
- SFTP：上传到当前目录。目录切换尚未完成时拒绝投放，避免文件进入旧目录。
- 只在终端/SFTP 内容区接收。侧栏、标题栏、标签栏和空分栏不会把文件转发给最后聚焦的会话。
- 未连接的会话不能上传，遮罩提示先完成连接。
- 文件夹保留层级、空文件夹和零字节文件；不可读项目显示错误，不再静默跳过。
- SSH 上传同样走独立 Rust SFTP 连接，不向终端粘贴路径，也不通过 PTY 写入文件内容。
- 上传进度和历史按标签独立展示，沿用暂停、继续、取消、失败重试、大文件分片和安全覆盖。

## 标签和侧栏会话拖动

- SSH / SFTP 标签共用原生 `NSDraggingSession`：拖到标签栏中相邻标签旁，按鼠标所在标签中点确定合并与插入位置；非空内容区按方向创建左/右/上/下分屏，不执行中央合并。空工作区中央仍可接收第一个标签。
- 四向分屏热区向内延伸至当前分栏宽/高的五分之二（40%），无固定像素上限；重叠处按距离对应边缘的比例选择方向。每次拖动更新及松手时读取最新可见分栏尺寸，窗口或分隔条调整后重新计算热区与预览。标签栏优先处理合并与排序。
- 跨窗口按照实际命中的分栏投放；既有 runtime 不重连、不停止，SFTP 路径和终端表面保持不变。目标接管成功后来源才移除，接管失败撤销临时分栏。
- 左侧 SSH 会话普通拖动创建新终端，按住 Option 创建新 SFTP；预览随 Option 更新，松手时确定类型。原有会话配置不移动、不删除。
- 已打开的标签可以拖出 Snake 创建独立窗口；侧栏会话拖到窗口外取消。标题栏、侧栏、弹窗覆盖区不是标签投放目标。
- 拖动单标签到自身分栏边缘会留下一个可关闭的空分栏；移动到其他已有分栏时清理多余的空来源分栏。
- 事件监听器只负责识别开始拖动的鼠标阈值和 Option/Escape 状态；提交与清理由原生拖动目标/源的生命周期回调负责，不在全局 mouse-up 回调里移动标签。

## 与窗口/标签拖动的边界

| 拖放内容 | 类型 | 接收者 |
| --- | --- | --- |
| Finder 本地文件/文件夹 | `public.file-url` | 当前命中的 `FinderUploadHostingView` |
| Snake 工作区标签 | `com.snake.workspace-tab`，仅接受当前进程的活动事务 | Bonsplit 和窗口协调器 |
| 左侧 SSH 会话 | `com.snake.ssh-profile`，仅会话 ID 与事务标识 | 工作区原生拖动协调器 |
| SFTP 远程文件引用 | `com.snake.remote-file-reference` | 原有 SFTP 互传处理 |

`FinderUploadSurface` 是工作区标签内容的 AppKit 宿主，包含 SwiftTerm/SFTP 视图。原生接收层随内容重挂载到目标窗口，不缓存屏幕坐标。原生窗口委托提供后备路由：从本次拖放的窗口坐标遍历视图，检查实际 bounds、visibleRect、当前标签和遮挡状态，选择鼠标下的分栏，而非键盘焦点所在分栏。

窗口移动、调整分栏宽度以及标签独立窗口后，下一次拖放重新换算坐标。原生工作区载荷必须匹配当前进程活动事务，不接受其他进程或失效拖动伪造的 ID。非 Finder、非工作区类型交回 SwiftUI 的原有处理。Bonsplit 在原生路由模式中只提供不拦截鼠标的几何标记；分屏预览由协调器临时添加，结束或 Escape 取消时清理。上传提示层不参与普通鼠标命中测试。

`WorkspaceHostingView` 保留工作区和 Finder 类型的原生祖先接收注册，防止 SwiftUI 视图更新覆盖注册。终端与文件表内使用 `FinderUploadArea` 标记上传区域，路径栏和连接带不接受文件投放。窗口委托保留后备路由；窗口拖动仍由 AppKit 处理。窗口默认转发拖动目标消息的行为参见 [Apple NSWindow 文档](https://developer.apple.com/documentation/appkit/nswindow/registerfordraggedtypes(_:))。

SFTP 文件表的 SwiftUI `SFTPFileDropDelegate` 同时接收 Finder 文件 URL 和远程文件引用，避免依赖仅处理远程互传的子级接收层向上传递 Finder 事件。两种来源显示各自提示；工作区标签和侧栏会话载荷被拒绝。本地文件通过共享 URL 校验器解析 Data/NSURL 表示，保序去重，整批解析成功后复用 `SFTPRuntime` 上传队列。目标目录在松手时捕获，解析期间切换目录不改变本批目标，断开/重连会废弃尚未提交的批次。

工作区拖动由 macOS 15 `NSWindow.beginDraggingSession` 发起，不从透明的几何标记视图发起。期间在可见工作窗口临时安装只注册工作区类型的 AppKit 接收视图，结束后移除；普通点击及 Finder 拖放时不存在这层覆盖。原生 pasteboard 并非系统级私有存储，载荷只含 ID 和随机事务号，接收端还必须核对当前活动事务。

## 上传数据流

### 2026-09-10 上传反馈

- SSH 上传入口位于连接带右上角，预留进度宽度；窄分栏隐藏路径等次要信息。首次上传前不占空间，完成后保留可点击的上传记录图标。
- SSH 与 SFTP 共用直接观察 LocalUploadCoordinator 的进度/记录组件，点击进度或图标打开当前标签的记录。
- 上传准备和传输期间显示蓝色上传图标脉冲动画；百分比取自当前文件真实传输量，不模拟字节进度。减少动态效果开启时停止动画。
- 当前连续提交的上传全部结束且无失败、取消或跳过时，显示绿色勾与 100% 约 4 秒，然后收为记录入口；不会为动画延迟网络传输或远程提交。
- 批次结果包含目录创建、跳过、取消和失败；仅目录上传无文件级记录时，详情仍显示结果摘要。暂停、继续、取消和失败重试保留原有行为。
- 本轮通过自动化测试验证反馈状态；真实 Finder 操作、进度入口点击和浅深色页面由用户验收。

1. 从本次 NSPasteboard 的每个 item 读取文件 URL，验证为本机 URL，保序去重；混合非法项目时整批报错。
2. 在松手时固定远程目标。松手后切换标签、终端 `cd` 或 SFTP 导航不会改变这批任务的目标。
3. `LocalUploadCoordinator` 串行准备同一标签的批次，避免多个同名冲突确认互相覆盖；文件内部仍按设置并发分片。
4. 扫描本地文件，规范化 macOS 路径别名，再按路径组件计算目录相对路径。不能以 `/tmp` 原始字符串长度截取枚举器返回的 `/private/tmp` 路径。
5. 调用既有 Rust SFTP 分片/续传接口。零字节文件使用零长度 part；UI 进度分母与实际文件大小分开处理。
6. 同名文件先询问；确认覆盖后上传隐藏 part，合并 staging，最后 `mv` 替换目标。上传期间旧文件保持不变。
7. 传输成功更新记录，SFTP 再刷新目录。刷新错误不改写已经成功的上传结果。

原有的临时 bash/zsh/fish 路径 Hook 继续使用，不新增远程配置文件写入。上传本身不新建凭据后端、不绕过主机密钥验证，也不改变窗口关闭策略。

## 自动化验证

默认 Swift 测试覆盖：

- Finder URL 保序、去重、中文/空格/百分号及类型隔离。
- 非法项目、不存在文件和未连接标签。
- macOS 路径别名下的目录层级与空文件夹。
- 双分栏实际命中、隐藏标签排除、侧栏/标题栏拒绝。
- 接收视图重挂载到另一个窗口、窗口移动后继续接收。
- 取消拖动清理遮罩、失效坐标不再触发上传。

Rust 测试补充零长度传输与取消行为；Bonsplit 测试补充拖放类型隔离。

```sh
swift test
swift test --package-path Vendor/Bonsplit
cargo test --manifest-path Rust/snake_core/Cargo.toml
```

本机真实传输集成测试默认跳过，需明确设置测试目录：

```sh
SNAKE_LOCAL_SSH_FIXTURE_ROOT=/tmp/snake-finder-upload-<本机测试目录后缀> \
  swift test --filter FinderUploadIntegrationTests
```

该测试只连接 `127.0.0.1:49326`，使用当前 macOS 用户及该测试目录的 `client_key`。前提是对应 sshd 已运行，且已在 Snake 中核对并信任测试服务的主机密钥；测试不会自动接受未知密钥。它创建独立 SQLite/UserDefaults 和随机测试子目录，不改写用户会话配置；结束后只清理自己创建的测试子目录。

集成测试已验证真实 SSH/SFTP：中文文件名、层级目录、空文件夹、零字节文件、4 并发分片（测试将阈值临时降至 1 MiB）、终端实际 OSC 7 与 `cd`、换窗接收、投放后目录变化和安全覆盖，并逐字节比较上传结果。

## 打包 GUI 人工验收清单

自动化测试调用真实 AppKit 拖放目标与真实 SSH/SFTP 链路，但不等同于真实 Finder 鼠标跨应用拖动。以下需在重新打包后的应用中逐项复测：

- Finder 单文件、多文件、文件夹分别拖到终端文字区、终端空白区、SFTP 文件行与空白区。
- 拖动提示出现且路径正确；松手后能看到进度，完成后文件真实存在。
- 调整窗口位置、左右/上下分屏、标签拖出独立窗口及合并后重复上传。
- 标签排序/边缘分屏、SFTP 远程互传、窗口标题栏拖动不被 Finder 接收逻辑拦截。
- Escape 取消后可正常选中终端文字、输入命令并发起下一次文件拖动。
- 多显示器、浅色/深色及系统权限提示场景。

实际跨应用鼠标拖动本轮自动化未能可靠完成，未把该项标为通过。调试应用使用本地 ad-hoc 签名，不代表 Developer ID 公证发布。
