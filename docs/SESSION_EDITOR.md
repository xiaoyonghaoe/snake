# 紧凑会话编辑页

## 布局

- 编辑弹窗为 840×600pt；标题区 60pt、底部 56pt、水平边距 20pt。
- 左列宽 188pt，包含 88pt 头像、单行四个预设图标、完整“选择照片…”／“重新选择照片…”按钮和握手反馈。按钮标签固定内容宽度，外层承担剩余宽度，避免边距挤压文字。
- 右列按会话名称／标签、主机／端口、用户名／认证方式双列排布；私钥选择为条件行，密码／口令与查看按钮同一行。控件约 32pt、行间距 12pt。
- 沿用 Snake 现有 SF 系统字体与浅深色 token；地址、端口、密码、指纹用等宽字体。不增加装饰卡片。
- 常规内容按单页安排；两列保留按内容启用的滚动兜底。长测试信息在左侧 112pt 详情区滚动，不推动表单或底部操作按钮。

## 密码

- `CredentialRevealController` 持有内存草稿、用户修改标记和查看授权。认证成功后，没有草稿才读取凭据回填；已有草稿则只授权显示原输入。
- 读取回填不设置修改标记；`valueToSave` 仅返回用户主动修改的非空草稿。空值沿用保留旧凭据语义，不表示删除密码。
- 30 秒、手动隐藏、失焦、进入后台恢复圆点，草稿不丢失。再次查看重新进行系统认证。
- 关闭表单或切换认证方式清空草稿、修改标记和授权，并使迟到回调失效。切换认证方式时不把原密码引用带入新的私钥口令认证方式。
- 继续保留视图销毁期间同步清除、异步 UI 通知的保护，不更改加密格式或 Rust 接口。

## 连接测试

- `SessionConnectionTestController` 独立维护 idle/testing/success/failure 状态和目标快照；不复用保存表单的错误变量。
- 测试按钮仍在底部左侧。照片按钮下方显示测试中、SSH 握手成功或失败，以及主机、端口、算法和指纹。它不验证账号密码，不显示“登录成功”。
- 主机或端口变化清空旧结果并作废请求 ID；关闭表单同样作废。底层握手可完成，但其过期结果不会发布到新目标。

## 用户验收

- 1024×700 主窗中打开编辑页，检查浅／深色的密码和私钥模式是否常规内容无需滚动。
- 查看按钮在原框回填；修改、隐藏、再查看均保留输入，取消表单不保存。
- 检查照片选择、重新选择、头像裁剪，按钮文字无省略。
- 点击底部测试，确认结果只在照片按钮下方；长指纹可完整查看，测试失败不挤占表单。
- 测试途中更改目标、取消编辑、切换认证方式，确认不出现过期结果、错误回填或保存闪退。

页面与系统身份验证由用户验收；自动化只使用模拟验证、测试凭据及握手结果，不启动用户应用或读取真实秘密。
