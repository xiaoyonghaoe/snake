# SSH 会话卡片与磁盘映射标签

## 行为

- 启动新工作区打开一个 SSH 会话标签。双击标签栏尾部空白在该分栏新增会话页；顶部右侧磁盘映射入口新增映射标签。
- 顶部仅保留 Snake 标识与磁盘映射；新建配置在 SSH 卡片页操作，独立窗口使用标签右键或拖拽。
- 设置的“外观”页提供浅色与深色选择，默认浅色，UserDefaults 保存选择并同步所有窗口。
- 搜索和多选标签属于当前会话标签；Command-K 聚焦搜索，必要时先新建会话页。
- 卡片的按钮、双击和右键连接操作原位转换当前标签。Bonsplit TabID、WorkspaceTabID、标签顺序和分栏不变，重复点击不会创建第二个连接。
- 卡片拖动仍创建新连接：普通拖动为终端，Option 为 SFTP。管理标签也支持分屏、换窗；查询和选择跟随运行时。
- 映射状态与配置全局共享，关闭管理标签不卸载磁盘。管理页不注册 Finder 上传表面。
- 关闭最后一个标签保留空分栏；红色按钮继续保留工作区供 Dock 恢复。拖出标签创建窗口不额外添加会话页。

## 实现边界

管理运行时不绑定 SSHProfile。connectChooser 以明确的 TabID 和最新配置执行单次转换，随后使用 Bonsplit updateTab 更新标题和图标。
配置编辑和磁盘映射弹窗归属发起操作的页面窗口，数据仍使用原有存储。Rust、凭据和传输协议未改变。

## 验证

自动化覆盖原位转换、ID 保持、重复连接拒绝、缺失配置、分栏目标、管理标签换窗状态、独立搜索与标签筛选状态、关闭空分栏规则，并回归现有拖放测试。

补充覆盖尾部双击的目标分栏、空分栏和失效分栏回调、动态尾部宽度与溢出后滚动位置，以及外观保存与重新加载。实际鼠标双击、拖拽和设置页面交互仍交由用户验收。

按用户要求，页面测试由用户执行。本轮不自动操作应用 GUI；重点人工检查：卡片布局与搜索焦点、两种连接原位转换、管理页分屏/换窗、Finder 上传、映射横向滚动、深浅色、关闭窗口与 Dock 恢复。
