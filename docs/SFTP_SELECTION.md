# SFTP 多选与删除键

- 单击选择一项，Command 点击增减选中项，Shift 点击按当前显示顺序选取锚点到目标的连续区间；Command-Shift 将该区间加入已有选择。
- 空白单击清除选择。右键删除已选项时删除整组选中项，右键未选项的删除操作仅针对该项。重命名、权限等其他右键操作仍针对点击项。
- 点击文件行或空白将输入焦点移交文件列表，路径框失焦时恢复当前目录。Delete/Forward Delete 仅在文件列表获得焦点时申请删除；路径框编辑时仍正常删除文字。
- 删除弹窗捕获目标快照，统一展示数量和名称并警告不可恢复。确认后逐项串行删除，目录复用既有 rm -rf 接口，软链接只删除链接本身。
- 一项失败不会阻止剩余项；完成后刷新原目录，用户已导航至其他目录时不强行跳回。失败汇总保持可见，点击“知道了”清除，不自动重试破坏性操作。
- 自动化覆盖选中集合、范围锚点、上下文目标、重复/危险路径过滤与软链接删除策略。真实鼠标多选、输入框焦点和 Delete 键交互按用户要求由用户验收。
