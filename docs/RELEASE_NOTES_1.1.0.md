# Snake 1.1.0

## 本次更新（相对 1.0.0）

- 凭据加密存储，验证身份后可查看与编辑已保存密码；优化会话编辑布局和测试连接反馈。
- 终端增加 Tokyo Night 浅深色主题、日志关键词与输出字段高亮，以及当前 Shell 的彩色 `ls/ll` 配置。
- SFTP 支持文件和文件夹并行下载、可选远端 SHA-256 / MD5 校验；校验不可用时提示未校验，不阻止正常传输。
- 优化 SFTP 新建／上传右键菜单，增加文件检索及可自定义的检索、删除、上传快捷键。
- 修复设置窗口打开后主窗口 Command-W 的命令路由，保持关闭当前标签行为。
- 提供可拖入“应用程序”的 DMG，补齐独立安装后的终端资源及依赖许可证。

## 下载与安装

- 文件：`Snake-1.1.0-macos-arm64.dmg`，同时提供 `.dmg.sha256`。
- 系统：macOS 15+，Apple Silicon（M 系列）；本次不包含 Intel 版本。
- 打开 DMG，将 Snake 拖到 Applications，复制结束后推出 DMG。
- 更新前退出旧版；已有用户配置不随安装包分发，也不会因复制应用被清空。

## 发布限制

当前构建为本地 ad-hoc 签名，未完成 Developer ID 签名与 Apple 公证，首次打开可能被系统拦截。
详见 [安装说明](INSTALL.md)。页面及真实安装后的连接行为由用户验收。
磁盘映射仍需单独安装 macFUSE / sshfs；本安装包不自动安装系统依赖。
本次未修复既有挂载 `invalidMapping` 测试问题，不将其列为已通过项目。
