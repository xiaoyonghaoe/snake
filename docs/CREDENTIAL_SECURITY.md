# 凭据加密与身份验证查看

## 存储与迁移

- `CredentialStore.save/readData/delete` 仍为调用接口。终端、SFTP、上传及其他调用方不需要为普通连接执行 LocalAuthentication。
- 使用 CryptoKit AES-256-GCM 加密整个账户—秘密字典，磁盘格式为 `{"version":1,"sealedBox":"<Base64>"}`。combined sealed box 包含随机 nonce、密文及认证标签；固定 AAD 为 `com.snake.credentials:v1:AES-256-GCM`。每次写入使用新的随机 nonce。
- 256 位随机密钥保存在 generic-password 钥匙串条目：service `com.snake.credentials.encryption`，account `master-key-v1`，`WhenUnlockedThisDeviceOnly`，关闭同步，不设置每次连接需指纹的 ACL。不在配置、数据库或二进制中保存密钥。
- `~/Library/Application Support/Snake/credentials.json` 保留原路径；父目录 `0700`、文件 `0600`。存储锁串行化读写；临时文件只写密文，校验解密后原子替换，失败清理临时密文。
- 启动初始化、读取、保存及删除都会检查格式。旧 `[String:String]` 明文文件整体迁移，包括本次未连接的其他会话；无凭据文件时启动不创建密钥或空文件。迁移失败提示用户并保留原文件，不回退明文，不制作明文备份。
- 旧 `com.snake.ssh.credentials` 条目仅在新存储没有对应账户时兼容读取；读取成功后写入加密文件，保留旧条目。删除凭据时同步删除对应旧条目，防止兼容路径恢复已删除凭据。移除旧调试明文缓存。
- 不支持的版本、密文认证失败、钥匙串访问失败或缺失密钥均停止读写。已有密文时绝不自动创建替代密钥。

## 身份验证与界面

- 密码和私钥口令原输入框旁提供“查看／隐藏”；无草稿也无已保存引用时禁用。新建会话输入密码后也可验证身份查看当前草稿。
- 每次查看创建新的 `LAContext`，复用时长设为 0，使用系统 `deviceOwnerAuthentication`。系统提供 Touch ID、Mac 登录密码，亦可能提供已配置的 Apple Watch；Snake 不收集、接收或保存系统密码。
- 身份验证通过且来源窗口仍在前台后，没有草稿时读取已保存值，回填原框并支持编辑；已有输入时仅显示当前草稿，不读旧值覆盖。区分读取回填与用户编辑，仅查看不触发凭据写回。密码输入留空仍保留原凭据。
- 明文最多显示 30 秒。手动隐藏、窗口失焦、应用进入后台时恢复圆点，保留内存中的草稿；表单关闭或认证方式切换才清除草稿及查看授权。系统验证面板及钥匙串访问授权可能暂时抢占焦点；身份验证／读取完成后最多等待 1.5 秒，让原窗口恢复可见、应用激活和输入焦点，并在不同主队列轮次再次确认。未恢复时明确提示，不静默隐藏、不强制激活窗口、不跳过身份验证。
- 每次操作持有独立请求 ID。关闭、切换或隐藏后，迟到的验证／解密回调均无效。验证取消不报错，验证不可用／失败有明确提示，不提供绕过路径。
- 不自动写入剪贴板、日志或持久化 UI 状态。已授权的明文输入框支持标准文本编辑操作。Swift 字符串及框架内部拷贝无法保证逐字节清零；隐藏只撤销可见状态，不承诺清除编辑草稿。
- `CredentialRevealController` 将秘密存储与 UI 通知分开：普通更新合并到下一次主队列执行，原生视图销毁时同步清除明文、取消请求及计时器，但不再通知正在销毁的 SwiftUI 图。不同原生观察视图有独立 ID，旧观察视图的拆卸不影响替代视图。

## 边界与运维

- 保护目标是磁盘静态凭据及正常界面查看。允许连接自动解密意味着它不是抵御已控制当前用户进程的安全隔离边界。
- 开发包使用 ad-hoc 签名；更新后系统可能重新请求钥匙串访问批准，区别于查看明文时的身份验证。正式发行需要稳定 Developer ID 签名；不通过放宽到任意应用访问来绕过批准。
- 密钥和加密文件必须配套。密钥丢失后先恢复原钥匙串；无法恢复时需人工另存原密文并重新建立凭据，本轮不提供自动重置／恢复入口，防止误覆盖。
- 原子迁移不能消除历史备份、APFS 快照、SSD 历史块或旧应用已有的进程内明文。迁移后不要同时运行旧版明文存储应用。
- 不新增 Rust API、数据库迁移、私钥文件复制或密码工具接入。

## 验收

自动化仅使用临时目录、测试生成密钥和模拟身份验证，不访问用户真实凭据或弹出系统验证：

- 加解密、随机 nonce、权限、重载、删除、完整迁移与幂等性。
- 原子替换失败保留原文件，临时密文清理；缺失／错误密钥、格式损坏、篡改、未知版本失败关闭。
- 验证成功、失败、取消、不可用、超时、失焦，以及关闭后的迟到回调；未授权不读取密码。

页面及系统验证由用户执行，尚不能以模拟测试代替：

1. 关闭旧版本，打开新包；如系统要求，批准该签名应用的钥匙串访问。启动迁移成功后已有会话仍可连接。
2. 编辑已保存密码及私钥口令会话，点击查看；分别验证 Touch ID／Mac 密码以及取消路径。
3. 先输入一个尚未保存的新值，再点击查看；验证后原框显示新值而非旧密码。关闭而不保存后磁盘中的旧值仍有效。没有草稿时查看会回填旧值，仅查看不修改再保存不应重写凭据。
4. 查看后等待 30 秒、切换窗口、切到其他应用、关闭表单、切换认证方式；均不继续显示明文，再次查看重新验证。
5. 新建会话未输入密码时查看按钮不可用，输入后验证查看草稿；密码与口令加密保存后，回归 SSH、SFTP、上传及现有映射认证流程。
6. 浅色／深色及 1024×700 窗口中检查按钮、长密码横向编辑、滚动区域与系统验证提示。

来源：[Apple AES.GCM](https://developer.apple.com/documentation/cryptokit/aes/gcm)、[Apple deviceOwnerAuthentication](https://developer.apple.com/documentation/localauthentication/lapolicy/deviceownerauthentication)。

## 保存闪退与验证后不显示的修复

- 用户报告 `20260912090148` 在保存后闪退。崩溃栈明确为 `dismantleNSView → CredentialRevealController.hide → @Published plaintext.setter → SwiftUI GraphHost → swift_beginAccess`：视图销毁期间同步发布变化，触发 Swift 独占访问冲突，不是 AES 加解密异常。
